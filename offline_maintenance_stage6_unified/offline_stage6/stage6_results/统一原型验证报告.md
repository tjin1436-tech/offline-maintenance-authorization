# 统一持久化原型验证报告

本报告只使用本目录实际运行及独立审计的数据。运行模式：full；开始时间（UTC）：2026-10-12T04:10:49.194Z。

## 1. 本轮完成的统一实现

同一份网关代码用于故障恢复与性能矩阵。执行路径为：签名请求校验 → SQLite事务预留次数并写PENDING → 独立HTTP机器人模拟器持久化签名回执 → 网关签署并持久化DONE → HTTP可信适配器验签 → 本地EVM登记 → 网关持久化同步确认。

网关和机器人各有独立操作系统进程和数据库。SQLite持久化配置为DELETE回滚日志、synchronous=FULL；故障恢复始终重新打开原工作数据库，正式归档为进程关闭并核验后的原始数据库字节副本。内存对照使用相同SQL与协议，将网关数据库改为:memory:，机器人仍持久化。

## 2. 环境与协议

- Node.js：v24.15.0；系统：win32 10.0.26200；架构：x64。
- CPU：AMD Ryzen 5 7640HS w/ Radeon 760M Graphics     。所有HTTP接口均为本机回环地址，开发链为Ganache 7.9.2。
- 故障：12类，每类3次；控制器在指定边界强制终止进程。
- 性能：2种网关存储模式 × 3种授权策略 × 3种连接场景 × 2种远端响应延迟 × 3次重复；smoke模式缩减为联网、0毫秒条件。
- 固定期限4000毫秒；Q90初始期限2000毫秒、上限6000毫秒；短/长断网1500/4500毫秒；五项离线请求在0%、20%、40%、60%、80%时刻计划发送。
- 远端中继注入0/50毫秒响应延迟，阻断授权和适配器路径；本地机器人路径保持可达。严格在线每次执行额外向授权服务验证。
- 运行单位是独立工作目录中的一组六次请求；先求组内中位数，再跨组汇总。没有把全部请求当作独立实验重复。

## 3. 完整性与故障结果

实际通过36个故障用例，记录39次真实强制终止；另有9项功能检查通过。U11每次分别终止机器人与网关，因此终止次数多于故障用例数。

| 场景 | 验证结果 |
|---|---|
| U01 预留前终止 | 配额和记录均未占用，重试只执行一次 |
| U02 预留事务中途终止 | 配额增加与PENDING插入一起回滚 |
| U03 预留后、机器人调用前终止 | 保留PENDING与配额，未知回执不升级为DONE，不自动重发 |
| U04 机器人完成、网关未写DONE | 重启查询独立持久化回执，恢复DONE |
| U05 DONE事务中途终止 | 回滚到PENDING，再通过回执恢复 |
| U06 DONE持久化后、返回前终止 | 原请求返回REPLAY，新请求受剩余配额约束 |
| U07 链上接受、本地同步标记前终止 | 重传产生DUPLICATE，链上记录数不增加 |
| U08 适配器响应丢失 | 未确认状态保留，重启后通过DUPLICATE完成确认 |
| U09 两条记录补传途中终止 | 第一条重复确认，第二条首次接受，队列有序完成 |
| U10 本地同步标记后、返回前终止 | 重启后队列已确认，不产生额外补传 |
| U11 机器人回执提交后终止两个进程 | 新机器人进程保留回执；新网关进程恢复DONE |
| U12 重启显式标记时间不可信 | 旧请求可返回已处理标记，新操作拒绝 |

功能检查还覆盖主体签名、错误范围、相同请求并发到达、同标识不同内容、重复安装授权不重置配额、最后一个配额位置竞争、过期授权，以及真实签名但与命令不匹配的机器人回执。

## 6. 持续运行与链上证据

统一持久化网关持续运行观察120.47秒，完成740项模拟命令，最终全部持久化且获得链上确认。期间定期补传并在授权接近到期时签发新授权；未注入进程故障或网络中断。

本轮总计1282条链上唯一记录、1570笔登记/提交交易，观察到9次幂等重复事件。交易回执在原节点关闭前重查，归档审计核对原始事件、签名、请求、回执、SQLite文件和本地同步标记。

新链重放结果见chain_replay.json；负对照见negative_controls.json。若这些文件未生成，不能把该项写为已通过。

这一时长的单次观察不构成长期可靠性保证，也不能说明此前Windows长运行退出原因已经修复。

## 7. 可以补入论文的表述

“为减少分层原型间的实现差异，我们在同一HTTP网关中集成执行前SQLite事务预留、独立机器人模拟器的持久化签名回执、完成记录及补传确认。该实现同时用于进程故障验证与端到端计量。36个预定义故障用例和9项功能检查符合预期，独立审计进一步核对关闭后的数据库、签名和链上交易。性能矩阵包含108组运行、648次计划命令，其中504次被接受。结果提供了同一软件实现下的恢复行为与运行开销证据。”

引用这些数值时必须同时说明本报告环境及范围，不能与旧Windows批次混合成同一组独立样本。

## 8. 仍然成立的边界

- 机器人是支持原子保存模拟执行计数与回执的接口模拟器；真实动作恰好一次、机械安全和维修质量未验证。
- 不覆盖断电、磁盘损坏、恶意存储回滚、密钥失陷、多网关共享配额或可信硬件时钟。
- 链下适配器仍受信；合约不独立校验Ed25519签名。开发链最终性及其自身数据库重启未验证。
- U03未知结果会占用次数并阻塞后续操作；这是保守语义，不是自动恢复成功。
- 集中式登记后端对照和真实网络/真实机器人验证仍未完成。
